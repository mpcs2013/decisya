# Address allow-list for deploy/tests/test_no_home_addresses.py (issue #120, G2 D1 guard a, T120-05).
#
# The scan reads every tracked and every not-ignored text file and fails on any IPv4 or IPv6 literal in a
# private, CGNAT, link-local, ULA or global range that is not covered below. A line is a CIDR (or a
# single address); a literal is allowed when it lies inside one of them. Blank lines and lines
# starting with # are ignored. Block definitions such as 10.0.0.0/8 (prefix /16 or shorter) and OIDs
# or versions with more than four parts are not addresses and need no entry.
#
# Only ranges that can never be a home network belong here. A home network address is the thing the
# scan exists to catch: never add one. A real address in the repository is a leak (ops.local/ stays
# git-ignored for private notes). The test also lists every entry that would admit a home or public
# range in REVIEWED_CANDIDATE_ENTRIES, so adding one here without review fails the test.

# fixed addresses on them. These two /24s are what the apps' trusted-proxy settings name.
