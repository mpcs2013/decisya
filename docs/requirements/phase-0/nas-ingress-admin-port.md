## Findings

1. No gap blocks the gate. One caution for G6 and Marco: the only proof "on a running Caddy" for the G4-178-01 probes, and the D3 check that the console on 8444 names the 8444 origin, is `deploy/tests/stack_smoke.py`. It needs a Linux Docker host and is not in the unit or CI suites or in the orchestrator's G4 re-run evidence. Until it has run (on a Docker host before merge, or at #132 bring-up), the Caddy-side behaviour is proven by `caddy adapt` structure and the path-matcher model, not by requests. The residual is recorded here rather than hidden. Closing it needs no new test, only a run.
2. The `every other interface` state (G4-178-03 a, runbook a3) has no automated assertion. This matches the G3 text, so it is not a gap.
3. ADR-0016 stays "Proposed" until Marco accepts it (criterion 3b).
