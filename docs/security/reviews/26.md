## Requested checks

- **C-5, `scripts`:** `dev` (`vite build --watch`), `build`, `typecheck`, `lint`, `test` and `test:e2e`. There's no install, exec, fetch or lifecycle script, and no `allowScripts`. `.npmrc` sets `ignore-scripts=true`, `save-exact=true`, `engine-strict=true` and `fund=false`. Every dependency is pinned exactly, and the list matches G1 Q6 plus the three G2 `@types` packages.
- **Lockfile spot-check** (Python parse, no npm): lockfileVersion 3; 326 packages, all `resolved` from `https://registry.npmjs.org/`; every one has a `sha512-` integrity. There are no `link`, git, file or tarball sources. The only `hasInstallScript` is `node_modules/fsevents` (optional, `os: darwin`). The root dependency and devDependency versions match `package.json`. This agrees with Marco's evidence. `npm audit --audit-level=high` today: 0 vulnerabilities.
- **CSP:** `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self'; font-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'; frame-src 'none'; worker-src 'none'`. It has no `unsafe-*`, nonce or hash. The Vite config sets `assetsInlineLimit: 0`, no modulepreload polyfill and no source maps, and `index.html` has no inline script or style (a test checks this).
- **SPA fallback and web root:**
  - The fallback serves only GET and HEAD, is mapped last, and opens only the constant `index.html`.
  - The 7 reserved prefixes use segment-aware, case-insensitive matching, are pinned by a test, and return 404 with an empty body.
  - `/assets` is a `UseWhen` branch over `PhysicalFileProvider(WebRootPath)`, with `ServeUnknownFileTypes=false` and no directory browsing. A missing asset falls through to the reserved-prefix 404.
  - The G4 fix is correct: `WebRoot()` builds the provider from the effective `WebRootPath`, or uses a `NullFileProvider`, so a default `wwwroot` under the content root can no longer be served by mistake. `The_configured_web_root_wins_...` pins it.
  - The traversal set covers `..`, `%2e%2e`, `%2f`, `%5c`, a drive path, `::$DATA` and a hidden file, with canaries inside and outside the root.
- **Logout:**
  - `WantsJson` requires an exact `application/json` media type with q > 0; `*/*` and `application/*` keep the 302.
  - `EnsureEndSessionLocation` requires status 302, an absolute URI, https (http only when `RequireHttpsMetadata` is off), and the Authority's scheme, host and port. Its message is fixed and never echoes the URL.
  - The response sets `Vary: Accept`. The antiforgery filter and `RequireAuthorization` are unchanged, and `LogoutJsonTests` covers Accept JSON without the header (403, session kept).
  - The SPA accepts only an `http:`/`https:` `redirectUri` and navigates with `location.assign`.
  - The code comments make no claim that `Accept` is a CSRF control. One sentence in the G2 note still reads that way: G6-26-01.
- **`/api/capabilities`:** the fallback policy and the membership gate apply, with no `RequireAuthorization()` override; `no-store`; 401 when anonymous. A tenant-less caller gets an all-false manifest. The tenant comes from the ambient context only.
- **SPA:**
  - No token reaches the SPA: `/bff/me` and `{redirectUri}` carry none.
  - It reads `__Host-decisya-xsrf` only after `/bff/me` answers, and sends it only as `X-XSRF-TOKEN` on same-origin non-GET requests.
  - It has no `innerHTML`, `eval` or web storage; `login-flow.spec.ts` asserts that both storage areas are empty.
  - Rendering goes through React text nodes only, including the email and role.
- **Supply chain on CI:** the guard runs before any install, and `npm audit signatures` runs on every SPA change.
- **Logs:** `SpaIndexMissing` (event 1807) is fixed text with no path. No new log statement carries PII or a token.
