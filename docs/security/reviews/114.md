## Rulings on the G4 deviations

1. **`dotnet ef` output options inside the lane: accepted.** The `..` and absolute values are already denied by `_outside`. `--output-dir` is resolved under `--project` as EF does it, and `decide_write` bounds the target. The default-folder gap is G6-114-06 (backlog).
2. **Backslash denied outside single quotes: accepted.** It is stricter than joining continuations, and Windows paths inside single quotes are still caught by `_outside`.
3. **`--` denied for `dotnet`: accepted.** It is stricter than G3.
4. **Single-dash `o d l p s t` deny: accepted as a stopgap, not as the final form.** A deny-list of first letters misses `-getResultOutputFile` (G6-114-03). An allow-list is the fix. Side effects to note: `-tl` is denied. The `report` prefix also denies MTP's `--report-xunit-trx`, which test-engineer's own rules tell it to use, so a rule-following test-engineer would freeze. Reconcile the agent text (backlog #83, main session). **Superseded in the re-check:** the allow-list replaced the stopgap, and `test-engineer.md` no longer names `--report-xunit-trx`. It now forbids report and output options and says that CI writes the TRX.
5. **Windows fail-open found and fixed: accepted.** `S_ISDIR(lstat(frozen/))` comes first, and any other state fails closed. A junction in place of `frozen/` reads as not-a-directory, so it is denied.
6. **Read/Glob/Grep hint in the allow-list deny reason: accepted.** It adds no command text. It is consistent with the freeze, which leaves the read tools open for the report.
