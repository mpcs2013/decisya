| L-1 | Low | fix-now | Fixed (re-check 2026-10-31, uncommitted) | `.claude/tests/test_dependabot.py` (`groups()`, `DependabotGroupTests`) | **Finding.** The parser only reads groups written inline as `name: { patterns: [...] }`. Re-check (2026-10-31, scope L-1 only; `git diff origin/main -- .claude/tests/test_dependabot.py`): **Fixed.**
- `groups()` now raises in three cases:

- `test_groups_are_exact_and_scoped` now asserts that every expected entry exists before it compares.
