## Evasion attempts on `RealmGuard.Offends` (summary)

- **Held:**
  - The `tests-x/` and `docs.old/` prefixes: `docs.old/y.md` is exempt only as Markdown, which is intended.
  - `Tests/`, `DOCS/` and `.CLAUDE/`: `Ordinal` makes these stricter, not looser.
  - `README.MD`: the guard exempts it, while CI triggers on it (case-sensitive `\.md$`). That is the safe direction.
  - Case-variant needles and the import directory.
  - A `.claude/tests` file with `DOCKER` or `Testcontainers`.
  - A skill asset `.csproj`.
  - `settings.local.json`.
  - A `.claude/tests/*.md` file: it follows the tests rule, and Claude Code does not load it.
  - The order of the checks: needle, then unconditional exemptions, then `.claude/tests`, then `.claude` Markdown, else offend. This fails closed for every unknown path.
- **Broke through:**
  - fenced ```` ```! ```` blocks and multi-line `` !` `` spans (G6-77-01);
  - `--- ` delimiters and unterminated frontmatter (G6-77-02);
  - nested `.claude/` Markdown (G6-77-03);
  - a parent directory ending in `.git` (G6-77-07, vacuous pass).
- **Re-check `7a0297e`:**
  - **Now held:** fenced and multi-line shell, `--- ` and unterminated frontmatter, nested `.claude` frontmatter, a `.git`-named parent directory, a mislabelled `in_scope` row, and a new exemption branch outside `ExemptionRules`.
  - **Still through (Low):** a Unicode-whitespace opener (G6-77-10) and `.claude` areas under `docs/` or `tests/` (G6-77-11).
- **Residual, as accepted at G3:** split strings, indirection through a scanned helper that never names the file, and mounts to a non-standard import path (F-77-2 → #29).
