## Bypass attempts that failed (the controls held)

- Removing a floor context from the file and the workflow together (`test_03`), and removing `changes` (`test_11`), are flagged.
- A one-hop or two-hop unrequired `needs` dependency (B10, B10b) is flagged.

- Spoofing the Dependabot exemption from a fork or another account is not possible (logins cannot contain `[` or `]`). The step reads its input through `env`, and `run:` has no `${{ }}`.
- The test is offline: no network or subprocess import, and it reads repository files only.
