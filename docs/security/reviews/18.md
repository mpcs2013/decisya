G6 checks that need no test:
- **Logger arguments: met.** `BffLog` takes only operation names and fixed reason codes. The exception path is F1.
- **Log level: met.** `Microsoft.AspNetCore` is at `Warning` in `appsettings.json`, and `appsettings.Development.json` does not override it.
- **Trace spans: met.** OTel ASP.NET Core 1.19 redacts the query string by default, so `code` and `state` stay out of spans.
- **Redis spans: met.** Aspire's embedded Redis instrumentation leaves `SetVerboseDatabaseStatements` at false; nothing sets it (checked by IL scan). Spans carry the command name, never the key.
- **Client secret: met.** It reaches the BFF only through the AppHost parameter or the environment. Tests generate their secrets at run time (`TestSecrets.cs`), and CI masks them.
- **Dependencies: met.** `dotnet list package --vulnerable --include-transitive` reports no vulnerable package for `Decisya.Bff`. No new package enters `Directory.Packages.props` apart from the already-pinned `Aspire.Hosting.Redis` and `Aspire.StackExchange.Redis`.
- **Generic errors: met.** `UseExceptionHandler` with ProblemDetails is in place. Back-channel 400s have empty bodies.
