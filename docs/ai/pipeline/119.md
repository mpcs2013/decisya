**Summary** (ADR-0017, `docs/architecture/release-supply-chain.md`)
- **Images:** `decisya-api`, `decisya-bff` (which also serves the SPA) and `decisya-migrator`.
  - Built with .NET SDK container publishing, so there are no Dockerfiles for the apps.
  - Distroless `10.0-noble-chiseled-extra` bases, pinned by index digest in `.github/release/base-images.Dockerfile`, which Dependabot keeps current.
  - `linux-x64` only, with no ReadyToRun or AOT: the Phase 0 NAS CPU is x86-64-v2, without AVX2.
  - Non-root user `1654`, and only the base image's six environment keys.
  - `Directory.Build.targets` DECISYA0006 enforces all of this at publish. `appsettings.Development.json` never ships.
- **Releases:** release-please, one version for the app, tags `vX.Y.Z`. Everything runs in one `release.yml`, with no PAT.
  - `permissions: {}` at the top.
  - `packages: write` and `id-token: write` only in `publish`, which runs no `dotnet` or `npm`.
  - `pull_request` runs `build` only. `workflow_dispatch` on `main` is a dry run that pushes `sha-<12>` tags.
- **Before any push, in `build`** (a fail-closed gate, because the packages become public):
  - a run-time **canary** proves the gitleaks layer scan detects a seeded token;
  - gitleaks scans every layer and the image config, with its config outside the scanned tree and `--ignore-gitleaks-allow`;
  - Grype applies the ADR-0015 policy;
  - the image config and file names are checked;
  - syft produces CycloneDX SBOMs (one per image, plus the SPA lockfile).
- **Signing:** cosign without keys, by digest, plus SBOM attestations.
  - Verification uses the exact identity `release.yml@refs/heads/main`, the issuer, the trigger, the commit SHA and the workflow ref.
  - Three negative cases must fail: an unsigned base image, the `ci.yml` identity, and a dry-run image checked as a release.
  - The pushed config digest must equal the scanned archive's.
- **Release PR exemption:** `claude-config`'s gates step exempts only `github-actions[bot]` on `release-please--branches--main` whose diff adds or modifies regular files among `CHANGELOG.md`, `version.txt` and `.release-please-manifest.json`. The Dependabot condition and the commitlint steps are unchanged. CLAUDE.md is updated to match.
- **CVE exception (Marco approved, 2026-10-04):** `libc6` CVE-2016-20013 on api, bff and migrator, expiring 2026-12-31. Ubuntu rates it negligible and won't fix it; it's a `crypt()` denial of service that .NET never calls. `image_scan.EXCEPTION_IMAGES` lets exceptions name the release images.

**Rollback:** revert the PR. No data step. If packages were already pushed, they stay in GHCR; delete them in GitHub (*Packages → decisya-* → Package settings → Delete*). A package made public can't be made private again.
