## G7 PR body draft

**BFF: cookie session, OIDC login, Redis ticket store, antiforgery, logout (0.06)**

Closes #18

**Summary** (ADR-0003, a hand-rolled BFF):
- **New `Decisya.Bff` host** on `https://localhost:7200`. It references only ServiceDefaults.
  - `GET /bff/login`: OIDC code flow with PKCE against the `decisya-bff` client; `returnUrl` must be local.
  - `GET /bff/me`: claims only, never a token; anonymous callers get `200 {isAuthenticated:false}`.
  - `POST /bff/logout`: needs a session and an antiforgery token. It redirects to Keycloak's end-session endpoint without `id_token_hint`, so no token reaches the browser (D3; Keycloak asks for one confirmation click).
  - `POST /bff/backchannel-logout`: validated logout tokens; idempotent.
- **Session:**
  - The cookie is `HttpOnly; Secure; SameSite=Strict`; the OIDC correlation and nonce cookies are `SameSite=Lax`.
  - Tickets sit in Redis (`ITicketStore`), protected with Data Protection bound to each session key, with a 10 h absolute lifetime.
  - A Redis outage fails closed: 1 s timeouts, no local cache, generic errors, and no key in exception messages.
  - The session key rotates on sign-in (session-fixation guard).
- **AppHost:** a pinned Redis resource (`decisya-redis`, persistent in dev, ephemeral in tests) and the BFF, wired to Keycloak and the existing `bff-client-secret` parameter.
- **Realm:** the back-channel logout URL, a roles mapper for the ID token, front-channel logout off.
- **Tests:** the five G3 MUSTs each with red-first tests (cookie flags and a token-leak scan across the whole flow; antiforgery; invalid logout tokens; production-config guards; session fixation and `returnUrl`), plus the G5 additions. The red phase caught two real bugs in logout-token validation.

Docs: docs/GETTING-STARTED.md, docs/requirements/nfr.md

**Packages:** none new. `Aspire.Hosting.Redis`, `Aspire.StackExchange.Redis`, `Microsoft.AspNetCore.Authentication.OpenIdConnect` and `Testcontainers.Redis` were already pinned in `Directory.Packages.props`. Container image: `docker.io/library/redis:8.10.2-alpine`, pinned by digest (verified twice) in `ContainerImages` and the sandbox image list.
