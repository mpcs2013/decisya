## G7 PR body draft

Closes #341

**What**
Adds the Ledger module (`Modules.Ledger` and `Modules.Ledger.Contracts`, schema `ledger`, role `decisya_ledger`) with accounts: create (name, one ISO 4217 currency, optional opening balance with its date, `Money` as `bigint` minor units plus `char(3)`), list with the limit use, read, rename, and currency change while the account holds no transaction. The two-account limit is one fixed value in code, enforced in the same transaction as the write under a per-space lock, for every space until EP-03's key ships. Owners write, members read; every read and write is tenant-filtered and authorised per object; every write is audited in the same transaction (ADR-0013 amendment 1: `audit.audit_records.subject_id`, ledger actions). The API contract is `openapi/ledger.json`, pinned by a contract test; money on the wire follows ADR-0027. A wrong content type, charset or a body over 4 KiB is refused with 400 `ledger.body_invalid` after authentication. Epic EP-02 (AC-02-1 to AC-02-5).
