## G7 PR body draft

### Summary
Adds the deployable stack for Phase 0 (ADR-0016, ADR-0018). The NAS bring-up is #132.

- **Compose from the AppHost:**
  - The AppHost's publish mode (`Aspire.Hosting.Docker`) generates `deploy/compose/docker-compose.yaml`. It is deterministic, pins five images by digest and uses placeholders for the three release images.
  - A hand-written overlay adds the networks, secrets and limits: `backchannel` and `idp` are internal, and only Caddy publishes 8443.
- **Edge:**
  - Stock Caddy with `tls internal` and a default-deny route table.
  - Keycloak admin paths are reachable from the workstation address only; ports 9000 and 8081 are never routed.
  - Back-channel logout is accepted from the `idp` network only.
- **Secrets:**
  - Secrets are files under `/run/secrets`, each mounted only into its consumers.
  - `stackctl.py` (`assemble`, `secrets init|rotate|retire`, `check`, `verify`, `export-root`, `up`) never prints a secret. Rotation computes the SCRAM verifier client-side and sends it over stdin.
- **Production hosting (#15 items):**
  - The key-per-file configuration source; `AllowedHosts`; forwarded headers trusted only from the edge.
  - Health is served on management port 8081 only, gated on the local port. Probes produce no spans.
- **Back-channel trust:** the BFF's OIDC client, YARP forwarder and the Api's JWKS client each trust the Caddy root per HttpClient, with no validation callback. The root is checked at startup and fails closed.
- **C-06 (database privileges):**
  - The stack's `decisya_migrator` is not a superuser.
  - `MigrationRunner` creates module roles with every `NO…` attribute, then reads them back and fails closed if any is elevated. Postgres 16 and later refuse those attributes in `ALTER ROLE` for non-superusers.
  - PUBLIC loses `CONNECT` on every database.
- **CI:**
  - The new `deploy-guards` job always runs, with no path filter or skip condition. It runs, in order:
    1. the home-address scan;
    2. a drift check that rebuilds and republishes the Compose file and compares it with the committed one;
    3. static guards over `docker compose config` and `caddy adapt`.
  - The image scan adds `caddy` and `otelcollector`.
- **Fixed during G4** (the dev and test paths, not the stack):
  - The new Postgres init script ended Aspire's Postgres entrypoint when sourced. The AppHost tests hung until the fix.
  - Startup in the AppHost tests is now time-limited.

### Rollback
Revert this PR. Nothing persistent is created outside a stack folder. A local test stack is removed with `docker compose -p decisya down -v` from its stack folder. The dev AppHost volumes are not touched: the Postgres init scripts are a no-op without `DECISYA_STACK=1`.
