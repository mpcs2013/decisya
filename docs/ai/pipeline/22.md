## G7 PR body draft

**Tenant query filter, ITenantScoped rules and PostgresFixture (0.10)**

Closes #22

**Summary** (platform invariant 1, ADR-0001). This PR builds the tenant-isolation foundation that #21 (Modules.Tenancy) and every later module build on.
- **`Decisya.SharedKernel.Tenancy`** (no EF): `ITenantScoped`, `TenantResolution` (from the `tenant_id` claim: a tenant, none, or invalid; `default` is invalid, so it fails closed), `ICurrentTenant` and `[AllowCrossTenant("justification")]`.
- **`Decisya.Infrastructure.Persistence.TenantDbContext`:**
  - every entity must be `ITenantScoped`, or the model build fails;
  - a global `"Tenant"` query filter evaluated on each query, never cached in the model;
  - no tenant means zero rows, and an invalid tenant throws before any SQL;
  - `TenantId` is required and a concurrency token, so a detached update or delete carrying another tenant's id fails;
  - owned types must live in the owner's table;
  - sealed `SaveChanges` rejects untenanted, mismatched or re-tenanted writes before any SQL.
- **`Decisya.ArchitectureTests`**, rules that scan the compiled IL, including lambdas and async bodies:
  - every mapped entity is `ITenantScoped` (the Done-when: red on a deliberate violation, then green);
  - `TenantId` is immutable;
  - the filter-bypass calls (`IgnoreQueryFilters`, raw SQL, `GetDbConnection`, `EntityEntry.GetDatabaseValues`/`Reload`) are allowed only in `[AllowCrossTenant]` types with a justification;
  - no bulk update may move rows to another tenant.
- **`Decisya.TestInfrastructure.PostgresFixture`:** a pinned Postgres 18 with a database per test and a random password.
- **Two-tenant isolation tests** on real Postgres.
- **Confirmed EF hazard, mitigated:** `EntityEntry.GetDatabaseValuesAsync`/`ReloadAsync` ignore the tenant filter. They are banned outside audited `[AllowCrossTenant]` types, pinned by tests that fail if EF ever changes, and recorded in ADR-0001 and the threat model.
- **For #21:** the module-scaffold and isolation-test skills now describe the real API, and `prereqs.py module-scaffold --phase tenancy` reports every prerequisite present.
