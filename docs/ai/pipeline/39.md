**Title:** chore(claude): harden hooks and gate checker

Hardens the Claude Code guardrails in `.claude/`. The ten items come from the issue, and the parse-based sandbox lint is split into #52. Threat model: `docs/security/threat-models/claude-hooks-hardening.md`. Review: `docs/security/reviews/39.md`. Runbook: `docs/runbooks/issue-pipeline.md`. Pipeline record, including red/green evidence for every item: `docs/ai/pipeline/39.md`.

- **Hooks**
  - Registered with `$CLAUDE_PROJECT_DIR`, so they work from any working directory.
  - For project agents they fail closed on any error, including a broken `boundaries.json` or a hook library that can't load. The main session still fails open.
  - Commands and paths larger than the checkable size are denied.
- **Agent command policy** (project agents only; the main session still prompts)
  - No package or tool installs: `dotnet add … package`, `dotnet package add`, `dotnet new|tool|workload install`, `dotnet nuget add`, `aspire add`, `gh extension install`, `pre-commit try-repo`.
  - No state-changing `gh` commands on issues, runs, repos, secrets, variables, `gh api` or PR merge.
  - Global flags (`gh -R`), `.exe` names and quoted verbs don't get around it.
- **Narrower agent grants:** backend-dev and devops list their `dotnet` and `gh` verbs one by one. `lint.py` rejects wildcard verbs, and prefixes of denied verbs such as `dotnet p*`.
- **`git diff|log|show --ou*` denied** in `settings.json` for every session, because `--output` writes a file without a prompt.
- **Secret guard**
  - Reads commands the way bash does: quote state and heredoc bodies carry across lines, and continuations are handled.
  - Only a quoted heredoc owned by `git commit` or `gh pr|issue create|comment|edit` counts as message text.
  - Catches more near-literal forms of the names: globs, `@`, `:`, glued options, concatenation.
  - Stops blocking commit messages, `gh` bodies and grep patterns that only mention the names.
  - Runs in linear time: a crafted input that took 95 s now takes 0.4 s.
- **Audit log:** denies are recorded in the git-ignored `.agent-logs/hooks.jsonl`, with a fixed field list and no command text. It rotates at 1 MiB, and a logging failure never changes a decision.
- **`gates.py`**
  - A verdict counts only as its own line outside code fences; a competing copy makes the gate AMBIGUOUS.
  - A BOM is tolerated.
  - Only known verdict values count.
  - Artifact paths must be relative, inside the repository, a regular file, and inside the owner agent's write lane, checked on the resolved path too.
- **`lint.py`:** checks `boundaries.json` against its schema and checks agents and entries both ways against the frontmatter `name`.
- **Local commitlint**
  - A new commit-msg hook, `.claude/scripts/commitlint.py`, uses only the standard library and mirrors CI's commitlint 19.2.1 with config-conventional 19.1.0.
  - It matches 29 golden outputs from the real tool byte for byte.
  - `conventional-pre-commit` was removed from `.pre-commit-config.yaml`; the new hook replaces it.
- **CI**
  - The `changes` job prints the file list between `::stop-commands::` markers with a random token per run.
  - `claude-config` runs the `.claude/tests` unittest suite.
