## G7 PR body draft

**Title:** chore(claude): run agents in a network-isolated devcontainer sandbox (ADR-0010)

Agent sessions that change code now run headless in a devcontainer sandbox (ADR-0010): a `workspace` container (non-root, read-only root filesystem, no capabilities) whose only route out is an `egress` squid proxy with an approved allow-list. Spec: `docs/architecture/agent-sandbox.md`; threat model: `docs/security/threat-models/agent-sandbox.md`; review: `docs/security/reviews/36.md`; runbook: `docs/runbooks/agent-sandbox.md`; pipeline record: `docs/ai/pipeline/36.md`.

- `.devcontainer/`: workspace and egress images, `compose.yaml`, host launcher `sandbox.py` (up / claude / shell / down / reset / attach-prep), `precheck.py` (refuses to start on secret files, planted executables, nested `.git`), `host-review.py` (flags host-executed files an agent changed; run before reopening VS 2026, building or committing), managed Claude settings.
- Only the repository is mounted; `.git`, `.claude`, `CLAUDE.md`, `.devcontainer`, `.vscode`, `.pre-commit-config.yaml` and `global.json` are read-only inside, `.vs` is masked. No Docker socket, user-secrets, SSH agent or host Claude login.
- Egress allow-list (approved by Marco): `api.nuget.org`, `api.anthropic.com`, `platform.claude.com` (required by interactive Claude Code), NuGet certificate-revocation hosts (GET, port 80) as found in the proxy log, `www.microsoft.com/pkiops/` only. SNI is checked against the list.
- Dedicated Anthropic API key with a spend limit, passed only to the `claude` exec (`DECISYA_SANDBOX_ANTHROPIC_API_KEY`); `sandbox.py` refuses to start while a Claude login credential exists in the sandbox.
- Build output moved out of the repository (`UseArtifactsOutput`; host: `%LOCALAPPDATA%\decisya\artifacts`); `RepoPaths` reads the `Decisya.RepoRoot` test-assembly metadata. `artifacts/` git-ignored.
- `.claude/`: devops may write `.devcontainer/**` and `.vscode/**`; `.devcontainer/` classifies as ci-tooling; lint check against Docker-socket, secret-folder and privileged mounts. `CLAUDE.md`: sandbox working agreement.
- Dependabot: docker ecosystem for the sandbox images.

Verification: host and sandbox `dotnet build -warnaserror` 0/0 and 76/76 unit + architecture tests; 22 sandbox probes plus the G6 conditions (filesystem, privileges, egress, SNI, Docker Desktop routes, IPv6, persistence, bypass mode refused); Marco's `.env` start and mid-session canaries; headless and interactive Claude with the dedicated key.
