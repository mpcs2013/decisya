## G7 PR body draft

**Modules.Admin: platform-admin API for the Entitlements commands (0.13)**

Closes #25

**Summary.** This PR adds the first cross-tenant HTTP surface. A platform admin can start a trial, and grant or revoke a feature override, for any existing tenant. Every success is audited in the command's own transaction (#24).
- **Routes** (new `Decisya.Modules.Admin`, policy `Admin.PlatformAdmin` on the whole group):
  - `POST /api/admin/tenants/{tenantId}/trial`
  - `PUT /api/admin/tenants/{tenantId}/overrides/{featureKey}` with body `{reason, expiresAt?}`
  - `DELETE` on the same path

  Each returns 204 on success. Errors: 400 `tenant_invalid`, `feature_unknown`, `reason_invalid` or `expiry_not_in_future`; 404 `tenant_not_found`; 409 `trial_already_used`. DELETE of a well-formed unknown key gives 204 and one audit record, as in #23.
- **Who counts as an admin (#23 C-2):**
  - a new Keycloak mapper, `realm-roles-access-token`, puts a flat `roles` claim in the access token;
  - `CallerIdentity` is the only parser: exact, ordinal, and false for any non-string value; `realm_access` is ignored;
  - `ICurrentCaller.IsPlatformAdmin` is set once in `RequestCaller`, and is true only for `platform-admin` with **no** `tenant_id`;
  - the ADR-0012 handler precondition is now `None && IsPlatformAdmin`, so a non-admin is refused at both the policy and the handler.
- **Target tenant exists (#23 S-5):** the handlers ask `Tenancy.Contracts.ITenantExistence` under the target-tenant scope they already hold, after validation and before the transaction. No new grant or migration (**ADR-0012 Amendment 1, Accepted**).
- **One 403 shape:** every policy 403 now returns the same generic ProblemDetails (`type`, `title`, `status`, `traceId`). This **closes #21 S-2**: the `Tenancy.Owner` empty-body 403 is gone. Every API response carries `Cache-Control: no-store`.
- **The override reason over HTTP:**
  - the PUT body is strict JSON, at most 8 KiB, and also refused when `Content-Length` is missing and the limit can't be enforced;
  - a content type other than JSON in UTF-8 gets 400;
  - parse errors aren't logged, and `ToString` omits the reason;
  - static bans on HTTP and W3C logging, `EnableBuffering`, Npgsql `Include Error Detail` and `UseHttpMethodOverride`.
- `/api/admin` skips the tenant-membership gate. A test proves that every skipped route other than `/api/whoami` requires the admin policy.
- **`docs/GETTING-STARTED.md`:** how to refresh a local Keycloak (reset, or add the mapper by hand with `kcadm.sh` prompting for the password), and a dev-admin smoke check.
