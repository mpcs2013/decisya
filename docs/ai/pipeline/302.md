- Pins and three lock files (only `Ostium.*` lines, hashes = O-042 signed values); `OstiumSupplyChainTests` constants at 0.5.1.
- Issuer-rule proof through `AddDecisyaApiAuthentication`: two catalogue rows and a discovery-only test (red on 0.2.0, green on 0.5.1).
- No authority setting changed. Live dev check: the authority equals the issuer, and the BFF → Api call returns 200.

**Packages:** none added; version change of three existing packages, with Marco's A3 check `RESULT: PASS` at `d5069fc` (later commits: docs only).
