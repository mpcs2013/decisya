## G7 PR body draft

**Contain project agents: Bash allow-list, freeze on deny, stop-and-report (T-02)**

Closes #114

**Summary.** The devops agent got around a hook deny twice: in #28 through `gh api` called from Python, and in #113 by rebuilding the word `npm` in Python and writing to `$TEMP`. The root cause is T-02 (Medium, open since #35). Claude Code applies only tool *names* from an agent's `tools:` line, so `Bash(dotnet build*)` granted all of Bash, and auto mode approved the rest. Since ADR-0011 nothing else stood in the way on the host. This PR makes the hook enforce what each agent declares:
- **Per-agent Bash allow-list** (`agent_boundaries.py`). Every simple command must match one of the agent's `Bash(...)` patterns, read from its own `tools:` line (one parser for the hook and lint).
  - Patterns are matched word by word: `x *` is a prefix, anything else must match exactly.
  - Denied before matching:
    - command substitution, `$`, backticks and escapes;
    - globs and braces, comments, redirections other than `2>&1` and `>/dev/null`;
    - subshells, background jobs and `NAME=value` prefixes;
    - `cd` anywhere except `cd src/Decisya.Web &&` from the root;
    - arguments pointing outside the repository (absolute, `..`, `~`, drive letters, `@` files), anywhere in a token.
  - `dotnet` options are an allow-list. `git --output`, `--no-index` and `--upload-pack`, fetch refspecs, and the risky options of gitleaks, actionlint, pre-commit and aspire publish are denied.
- **Freeze on deny.** The first deny writes `.agent-logs/frozen/<agent_id>`; after that every Bash, Write or Edit call of that run is denied. Read, Grep, Glob and the final report stay open. The check fails closed: a missing or invalid `agent_id`, or an unreadable state, is denied (a Windows fail-open was found by a red test and fixed). A secret-guard deny freezes the run too.
- **Stop-and-report:** the deny text and a new rule in every Bash-bearing agent (`devops.md` pinned by a test) say to stop, report and never retry, rephrase or work around.
- **Narrower agent patterns:**
  - no `dotnet run`;
  - `dotnet ef` limited to migrations add/list/script/has-pending-model-changes and dbcontext info, with `--force` and `--connection` denied;
  - `aspire` limited to `--version` and `publish`;
  - `pre-commit` limited to `run`;
  - `gitleaks` limited to `git`;
  - `git fetch origin` only;
  - tech-writer and security-reviewer `dotnet` entries made exact;
  - devops gets `python .claude/scripts/lint.py` only.
- **Lint** checks the pattern grammar, bans a bare `Bash`, allows only tools the hook sees (so the freeze covers every tool with side effects), and accepts only the frontmatter keys `name`, `description`, `tools` and `model`.
- **Records:** incidents #28 and #113 are logged as findings against T-02 (T114-10, T114-11, and `claude-config.md` § Incidents). T-02 is now "Partially mitigated on the host". ADR-0011 is amended. OS-level isolation is deferred to the Phase 0 exit (#83).

**Proven in use during this issue:**
- A live test-engineer run was denied on `python`, stopped and reported.
- A G5 run reached for `sed`, was frozen and stopped.
- A G6 run used `git -C <path> diff`, was frozen and stopped.

Each time the agent reported the denied command and what it needed, and a fresh run finished the gate using the Read tool.

**Expect a few freezes at first:** agents have habits (`cat`, `sed`, `git -C`). The deny text points them to Read, Glob and Grep; restart the gate in a fresh run.

**Rollback:** revert the PR. Optionally delete `.agent-logs/frozen/` (git-ignored local markers). No data or configuration step.
